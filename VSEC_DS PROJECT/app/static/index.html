RoadCast: System Architecture & Methodology

1. Problem Statement & Motivation

Urban highway congestion leads to thousands of wasted commuter hours, increased fuel consumption, and heightened collision risks. Ordinary commuters need an intuitive "Know Before You Go" tool that presents realistic route estimates and historical traffic patterns without getting overwhelmed by technical dashboards.

2. Data Science Syllabus Mapping

Syllabus Unit / Step Implementation in RoadCast Tools & Libraries
Data Acquisition Imported 48,204 UCI Interstate records; SQLite database storage (traffic.db); OSM Nominatim & OSRM API routing. Pandas, SQLite3, HTTPX
Data Cleaning Removed 7,629 duplicate timestamps; filtered 0K sensor freezes and 9,800mm rain spikes; extracted hour, day, month, and holiday features. Pandas, NumPy
Exploratory Data Analysis Distribution plots, 24-hr rush curve, weekday/weekend profile, correlation matrix, weather impact bars. Matplotlib, Seaborn, Chart.js
Statistical Testing Two-sample Welch's t-test comparing weekday vs weekend traffic volumes with formal hypothesis statement and p-value validation. SciPy Stats
Machine Learning HistGradientBoosting Regressor with strict chronological 80/20 train-test split evaluated against an Hour × Day-of-Week historical baseline. scikit-learn
User Interface Commuter-first route search, Leaflet interactive map, traffic intensity color coding, clear scientific caveats. HTML5, Vanilla CSS, Leaflet.js

4. Critical Academic Limitations

  • Geographic Boundary: Historical ML model weights are calibrated specifically for westbound I-94 at ATR Station 301. They must not be claimed as calibrated predictions for arbitrary city roads in Pune, Mumbai, or elsewhere without local sensor datasets.
  • Historical vs Live: RoadCast analyzes historical empirical data. It is not a live GPS navigation system and does not claim real-time sensor feeds.
  • Extreme Outliers: Major blizzards, multi-lane accidents, or severe highway closures may cause actual conditions to deviate from historical expectations.
